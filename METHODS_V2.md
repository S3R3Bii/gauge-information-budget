# Fixed implementation choices for the separate v2 analysis

The v2 protocol was committed at 1e498c6 before any recorded-data model fit. Its independently reconciled source was committed at 538ce29. The original 2020–2025 approval failure remains unchanged. The new period was chosen from the approval ledger, so it is an approval-informed retrospective cohort, not a blinded source collection.

The two feature families use identical complete training dates. Population standard deviation (ddof=0) is the declared training scale; a zero scale becomes 1 and is flagged. The residual response is centred on the training mean, with an unpenalized intercept. The ridge objective is mean squared residual error plus lambda times the squared coefficient norm. Production uses the resulting normal equations with n times lambda; the independent checker uses an augmented design and least-squares SVD. January 1 has season phase zero, with a 365.25-day period. These are fixed conventions, not empirically tuned improvements.

Development computes only the two development basins' 2020–2021 training fits and 2022 validation predictions. All 32 candidate fits and all 16 equal-basin objectives remain visible. Persistence is scored on the same dates. Each model and lag selects its penalty separately, with the predeclared absolute 1e-12 tie rule favoring the larger penalty. No held-basin validation outcome participates. Every source value is present; collection is not blinded.

Final execution requires a committed dependency freeze matching the committed development checkpoint. It fits each basin on 2020–2021 only and retains all 192 model/panel combinations and their predictions. The synthetic outage uses the lagged input date. Pair-model fallback uses the selected local model, while required additional-gauge records still define common support. The empty-qualifier sensitivity uses the same primary fits, excluding a date if any target/required input flag is nonempty; it does not retune.

The bootstrap retains every random block-start draw, the target-date order, each replicate estimate and its percentile endpoints. Four primary panels use a shared NumPy PCG64 generator with seed 20261029, sorted by basin/year. Circular 14-day blocks wrap within the year; replicate indices concatenate blocks and truncate to the original sample length. The present primary source has complete daily support. The independent checker requires consecutive calendar dates so the block unit cannot silently become 14 irregular observations. Five hundred replicates give exploratory conditional 90% intervals, with linear 5th/95th percentiles. Pair skill, local skill and their difference remain distinct. These intervals do not establish future-year or new-basin coverage.

Independent checks use separate SQLite source-date joins, augmented-design SVD fits, scalar forecasts, SQL error sums and a separate selector. They compare every eligible target date, feature bounds, qualifier union, prediction, common-support count, fallback and metric. Log-space and dimensionless numerical comparisons allow absolute 1e-8 difference; cfs metrics allow absolute 1e-4 plus relative 1e-10. Counts, dates, configurations, random draws, routing and selection are exact. These tolerances extend the protocol's cross-solver/replay contract to the recorded intermediate values; they are not statistical error bounds. Actual observed discrepancies are reported, never replaced by theoretical guarantees.

Twenty-three authored fixture methods cover calendar/leap boundaries, required source dates, qualifier union, exclusion of target-day additional data, mean-loss ridge scaling, the unpenalized intercept, zero scales, train-only normalization, clipping and inverse transform, selection ties, unavailable support, metric units, outage routing and a missing-freeze rejection. They use no recorded discharge outcomes.

Daily discharge in cubic feet per second is not water level, inundation or a flood-impact label. Later Approved records under artificial observation lags do not establish historical operational availability. This exercise cannot select an optimal monitoring network, estimate realized telemetry-outage frequency, value a gauge in dollars or support safety decisions.
