# The conditional value of an additional river gauge

Study14 compares target-only daily-flow history with one additional same-river gauge under fixed observation lags and a synthetic input outage. The protocol is fixed before full measurement retrieval or model outcomes. No result yet.

This is a retrospective simulation from later approved daily discharge records. It does not establish historical warning availability, water-level or flood-impact prediction, causal hydrology or operational benefit.
